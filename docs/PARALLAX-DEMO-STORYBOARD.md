# PARALLAX // Spatial MCP — Artifact Demo Storyboard

**Target duration:** 45–55 seconds  
**Format:** cinematic cyber-noir documentary + truthful product demo  
**Palette:** obsidian / cyan / crimson  
**Core proof:** `Observe → Act → See Again → Verify → Receipt`

## Demo rule

This film must distinguish concept footage from verified runtime evidence. No visual generated for the film may be presented as proof that a runtime action occurred. Verified claims must be backed by an inspectable PARALLAX receipt or live demo state.

## Scene 1 — The Entry (0:00–0:06)

Use the **builder desk** as the establishing frame. Start almost still, then accelerate with terminal overlays and 3D viewport motion.

**Text:** `I ENTERED THE OPENAI WEBMCP CHALLENGE.`  
**VO:** “I entered the OpenAI WebMCP Challenge as a vibecoder.”

Do not make the workspace look like a giant engineering team. It should read as one person working late.

## Scene 2 — The Question (0:06–0:12)

Match-cut from a 3D viewport on the builder desk into the **virtual-production studio**. Keep camera, chair, microphone, light and case spatially consistent.

Represent the agent only as cyan wireframes, scan volumes and HUD cursors.

**VO:** “Then I started asking a different question. What happens when agents stop talking about worlds and start changing them?”

## Scene 3 — Generated ≠ Verified (0:12–0:17)

Show a generic tool success event before confirmation.

**Text:** `SUCCESS` → then replace/interrupt with `GENERATED ≠ VERIFIED`  
**VO:** “A tool saying success doesn’t prove the world is right.”

The chair must not visibly move during this beat. The entire point is that the claim is unproven.

## Scene 4 — PARALLAX Loop (0:17–0:33)

Reveal the **canonical PARALLAX logo**, then use the **PARALLAX hero UI** as the visual grammar for the live loop.

1. **OBSERVE** — scan and record scene state.
2. **ACT** — move/rotate only the authorized chair.
3. **SEE AGAIN** — rescan the same scene.
4. **VERIFY** — compare before/after against the requested objective.
5. **RECEIPT** — display an inspectable structured record only after verification.

**VO:** “So I built PARALLAX. Observe. Act. See Again. Verify. Receipt.”

### Receipt fields shown on screen

- receipt ID
- objective
- authorized target
- before-state hash/reference
- after-state hash/reference
- verifier result
- timestamp
- policy/mandate reference

The receipt should be readable enough to look inspectable, not decorative sci-fi text.

## Scene 5 — Authority / Denial Proof (0:33–0:39)

Target the protected equipment case inside a crimson boundary.

**Text:** `OUTSIDE AUTHORITY` → `DENIED`

The case remains unchanged. However, **do not use unchanged state alone as proof of denial**. Show a distinct denial record containing:

- attempted action
- target
- governing mandate/policy
- denial reason
- dispatch status
- timestamp

**VO:** “And when an action falls outside the agent’s authority, the protected state stays unchanged.”

## Scene 6 — The Evolution (0:39–0:45)

Transform the studio boundary into the **AGENTROPOLIS city**. Cyan governed execution corridors propagate through the city.

**Text:** `I WAS A VIBECODER.`  
then  
`NOW I’M ARCHITECTING ACCOUNTABLE AUTONOMOUS AGENTS.`

**VO:** “Somewhere during this hackathon, I realized I wasn’t just building apps anymore.”

PARALLAX is shown as one spatial execution layer inside AGENTROPOLIS, not the whole system.

## Scene 7 — Still Building (0:45–0:50)

Return to the **builder desk**. PARALLAX loop and AGENTROPOLIS city are visible on separate monitors.

**Text:**

`STATUS: STILL BUILDING.`  
`HACKATHON PROTOTYPE → EVOLVING INFRASTRUCTURE`

**VO:** “PARALLAX is still being built. And this is only one piece of AGENTROPOLIS.”

## Scene 8 — Final Card (0:50–0:55)

Use the **canonical circular PARALLAX logo** center-frame.

**Text:**

`PARALLAX // SPATIAL MCP`  
`BUILT FOR THE OPENAI WEBMCP CHALLENGE`  
`GENERATED ≠ VERIFIED`  
`NEURO META X // AGENTROPOLIS`

Only show `NOW ON DEVPOST` when the Devpost submission is actually live.

**VO:** “Observe. Act. See Again. Verify. Receipt. That’s how AGENTROPOLIS moves.”

## Builder continuity

Use `neuro avatar parallax.png` as the identity reference for the Builder. Preserve the same face, hair, wardrobe language and PARALLAX branding across every human shot. Do not introduce additional team members or generic lab staff.

## What counts as the actual demo

The cinematic sequence explains the problem and system. The proof moment must be a real PARALLAX interaction embedded into or immediately following the film:

```text
1. Select studio scene
2. Observe and capture baseline
3. Issue authorized chair transform
4. Re-observe
5. Verify objective against observed state
6. Open generated receipt
7. Attempt protected-case transform
8. Show explicit denial record
9. Inspect both records
```

The audience should leave understanding one sentence:

> PARALLAX does not trust an agent’s claim that an action succeeded; it re-observes the world, verifies the outcome, and produces evidence.
