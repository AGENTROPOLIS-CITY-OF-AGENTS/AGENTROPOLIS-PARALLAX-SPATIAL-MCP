# Runtime extraction provenance

The initial TypeScript closed-loop runtime was extracted and generalized from the
AGENTROPOLIS WebMCP Challenge implementation, also licensed under Apache-2.0:

https://github.com/AGENTROPOLIS-CITY-OF-AGENTS/AGENTROPOLIS-WEBMCP-CHALLENGE

The extraction preserves the core sequence: bounded mutation, evidence capture,
verification, and capture-bound receipt. Challenge-specific studio UI, branding,
and submission code remain in the Challenge repository.

No source code or assets from Meng To's `sublevel-studio` were copied.

No source code from `propersloth/parallax-threejs` was copied in this extraction.
Its debugging feature set remains a comparison target for future original work.
